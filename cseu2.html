📘 Chapter 7 : Programming Methodology

1️⃣ What is Programming?

Giving clear, step-by-step instructions to a computer so it can solve a problem.

  • Clear instructions → correct result
  • Confusing → wrong result
  • Incomplete → error

Programming is mainly about thinking clearly.

2️⃣ What is a Problem in Programming?

A problem is something we want the computer to solve (e.g., add numbers, find largest, even/odd).

Every programming problem has 3 parts:

PartDescription
1. InputWhat we give to computer
2. ProcessWhat computer does
3. OutputWhat computer shows

👉 IPO Cycle (Input – Process – Output)
Example: Input → 5 and 3, Process → add them, Output → 8.

3️⃣ Steps in Program Development

  1. Problem Definition – understand requirement, input, output.
  2. Analysis – think about formula, conditions, repetition.
  3. Algorithm – write solution in simple English steps.
  4. Flowchart – diagram representation of algorithm.
  5. Coding – convert into programming language (C++).
  6. Testing and Debugging – run, find mistakes, fix.

🔹 Algorithm Example (sum of two numbers)

1. Start
2. Read two numbers
3. Add them
4. Display result
5. Stop

Properties of algorithm: steps clear, must finish (finite), correct order, no confusion.

🔹 Flowchart symbols

⚪ Oval → Start/Stop ▭ Rectangle → Process ▱ Parallelogram → Input/Output ◇ Diamond → Decision

4️⃣ Characteristics of a Good Program

  • ✔ Correct (right answer)
  • ✔ Clear (easy to understand)
  • ✔ Efficient (no waste of time/memory)
  • ✔ Reliable (works every time)
  • ✔ User-friendly (easy for user)

5️⃣ Types of Errors

Error typeExplanationExample
1. Syntax ErrorGrammar mistake in codeMissing semicolon
2. Run-time ErrorProgram crashes during executionDivide by zero
3. Logical ErrorProgram runs but answer is wrongUsing + instead of *

Logical error is hardest to find.

6️⃣ Language Processors

ProcessorFunction
CompilerConverts entire program at once. If errors, shows list. Faster execution.
InterpreterConverts line by line, stops at first error. Slower.

📘 Chapter 8 : Problem Solving – Methodology and Technology

How program flow is controlled – decisions & repetition.

1️⃣ Control Structures

Control structure decides which statement runs next.

TypeNameDescription
1.SequenceStatements run one after another (default).
2.SelectionDecision making (if, if-else, switch).
3.IterationLoops (while, do-while, for).

🔹 1. Sequence Structure

Step1 → Step2 → Step3. No skipping.

🔹 2. Selection Structure (Decision Making)

Example: if marks > 40 → Pass, else → Fail.

  • if statement: condition true → executes block, false → skips.
  • if-else: one block if true, another if false.
  • switch: many choices (1→Monday, 2→Tuesday…). Default optional.

🔹 3. Iteration Structure (Loops)

Repeat statements many times.

LoopTypeDescription
whileEntry-controlledcondition checked first – may not run.
do-whileExit-controlledruns at least once, then checks.
forEntry-controlledused when repetitions known (init; condition; update).

Loop Control Elements

Every loop has: Initialization → Condition → Updation

Empty Loop

Loop with no body: for(i=0; i<5; i++); – called empty loop.

Break Statement

Stops loop immediately, terminates entire loop.

goto Statement

Transfers control to a labeled statement. Not recommended, but important for understanding.

Algorithm vs Flowchart Difference

📌 Quick recap – control flow:
• Sequence → normal order
• Selection → if / else / switch
• Iteration → while, do-while, for
• break → exit loop
• goto → jump (avoid in modern code)
