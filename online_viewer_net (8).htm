📘 Chapter 9 : Overview of C++

1️⃣ What is C++?

C++ is a programming language. A programming language is a special language used to give instructions to a computer.

🧒 For a kid: Humans speak Hindi/English, computers understand only 0/1. C++ is like a translator – we write English-like instructions, and computer converts them to 0/1.

2️⃣ What does “High-Level Language” mean?

  • Machine language → 0 and 1 (very hard for humans)
  • High-level language → English-like (easy for humans)

C++ is high-level because you can write int age = 18; instead of binary.

3️⃣ If computer understands only 0 and 1, how does C++ work?

Computer does NOT understand C++ directly. Something converts C++ to machine language → that’s a compiler.

🧠 Compiler = translator + error checker. Takes your C++ program, checks for mistakes, converts to machine language.

4️⃣ What is a Compiler?

Compiler is special software. Its job:

  • Take C++ program written by you
  • Translate into machine language
  • Check for errors
  • Create an executable file

5️⃣ What is Compilation?

Compilation = converting high‑level program into machine code.

  1. You write code.
  2. Compiler checks syntax.
  3. If correct → creates executable.
  4. Program runs.

If syntax is wrong → compilation fails.

6️⃣ What is a Library?

Library = collection of ready-made code. Instead of writing code to print from scratch, C++ provides it in a library. We “include” that library.

7️⃣ What is a Header File?

In C++, libraries are included using header files.

#include<iostream>
  • #include → “bring this file”
  • iostream → header file (Input Output Stream) – contains definitions for cout and cin.

Without it, you cannot use input/output.

8️⃣ What is Stream?

Stream = flow of data. Like a water pipe. Data flows: keyboard → program → screen. Input stream = data coming in, output stream = data going out.

9️⃣ What is “using namespace std;”?

C++ standard library is named std. Inside it, things like cout, cin are defined.

If we do NOT write using namespace std; then we must write std::cout and std::cin. To write directly cout, we add this line.

🔟 What is main() Function?

Every C++ program must have int main(). Execution starts from main() – like the front door of a house.

1️⃣1️⃣ What does int mean in int main()?

int means this function will return an integer value. Usually we return 0.

1️⃣2️⃣ What does return 0 mean?

return 0; tells operating system: “Program finished successfully.” 0 means no error.

1️⃣3️⃣ What are Curly Braces { }?

Curly braces define block of code. Everything inside { } belongs to main function.

1️⃣4️⃣ What is a Statement?

Statement = one instruction. Example: cout << "Hello"; Every statement ends with ; (semicolon). Without semicolon → syntax error.

1️⃣5️⃣ What are Tokens?

Token = smallest part of program. In int a = 5; tokens are: int, a, =, 5, ;

Token typeExplanation / examples
Keywordsreserved words (int, float, if, else, return) – cannot use as variable names.
Identifiersnames given by programmer (age, marks, total). Rules: no start with digit, no space, no special chars except _, not a keyword.
Constantsfixed values (10, 3.14, 'A', "Hello") – do not change during execution.
Operators+ , - , * , / , = etc.
Special symbols{ } ( ) ; , etc.

Comments

Notes for humans, ignored by computer.

  • // single line
  • /* multi line */

📘 Chapter 10 : Input and Output in C++

How program interacts with user.

1️⃣ What is Output?

Showing result on screen. In C++ we use cout (character output).

cout << "Hello";

<< is insertion operator – inserts data into output stream.

Multiple output (cascading)

cout << "Sum is " << sum;

2️⃣ What is Input?

Taking data from user. In C++ we use cin (character input).

cin >> age;

>> is extraction operator – extracts data from keyboard into variable.

3️⃣ What are Escape Sequences?

Used for formatting output.

Escape sequenceMeaning
\nnew line
\thorizontal tab
\"double quote
\\backslash
cout << "Hello\nWorld"; // prints: // Hello // World

📘 Chapter 11 : Operation in C++

Operations are actions performed on data using operators.

1️⃣ Arithmetic Operators

OperatorMeaningExample
+addition5+2 → 7
-subtraction5-2 → 3
*multiplication5*2 → 10
/division5/2 → 2 (integer division removes decimal)
%remainder (modulo)5%2 → 1
Important: Division between integers removes decimal part: 5/2 = 2 (not 2.5).

2️⃣ Relational Operators

Compare values; return 1 (true) or 0 (false).

OperatorMeaning
>greater than
<less than
>=greater than or equal
<=less than or equal
==equal to
!=not equal

Example: 5 > 3 → 1, 5 < 3 → 0.

3️⃣ Logical Operators

Combine conditions.

OperatorNameExplanation
&&ANDboth must be true
||ORat least one true
!NOTreverses result

4️⃣ Increment and Decrement

  • ++ increases value by 1
  • -- decreases value by 1

Pre-increment: ++a (increase first, then use)
Post-increment: a++ (use first, increase later)

5️⃣ Assignment Operator

= assigns value. Example: a = 5; means store 5 inside a.

6️⃣ Type Casting

Converting one data type into another.

  • Implicit: float x = 5; → 5 becomes 5.0 automatically.
  • Explicit: int y = (int)3.5; → y = 3 (decimal removed).

7️⃣ Operator Precedence

When multiple operators, computer follows priority.

  1. ( ) parentheses
  2. ++ -- (post/prefix)
  3. * / % (multiplication, division, modulo)
  4. + - (addition, subtraction)
  5. Relational (< , > , <= , >= , == , !=)
  6. Logical && then ||
  7. Assignment =

Example: 2 + 3 * 4 → multiplication first: 2 + 12 = 14.

🧒 Little recap for you:
• cout << "hello"; → shows things on screen
• cin >> age; → takes input from keyboard
• operators (+, -, *, /) do math
• % gives remainder
• == asks “are they equal?”
• #include <iostream> must be on top for cin/cout.
