🌟 Chapter 1: Computer Fundamentals

1. What is a Computer?

A computer is a machine that works with information.

It does 4 simple things:

  • 1. Takes input (data)
  • 2. Processes it (thinks/calculates)
  • 3. Gives output (result)
  • 4. Stores it (remembers it)

That’s it. That’s the whole computer.

🔹 Real Life Example:
You enter: 45 + 55
Computer calculates → It shows: 100
And if you save it, it stores it.

💡 Information Processing Cycle

Input → Process → Output → Storage

Example: You type marks → Computer calculates total → Shows result → Saves file

2. Parts of a Computer

1️⃣ Input Devices – give data to computer.
Examples: Keyboard, Mouse, Scanner, Microphone.

2️⃣ Output Devices – show the result.
Examples: Monitor, Printer, Speaker.

3️⃣ CPU (Central Processing Unit) – the brain of the computer.

CPU has 3 parts:

  • a) ALU (Arithmetic Logic Unit): does addition, subtraction, comparison, logical (true/false). If you calculate 5+7, ALU does it.
  • b) Control Unit (CU): controls everything – tells memory, input, output what to do.
  • c) Registers: very small fast memory inside CPU.

🌟 Chapter 2: Software Concept

Software = Set of instructions given to computer.

3 main types:

  • 1️⃣ System Software: controls computer. Example: Windows, Linux (Operating System).
  • 2️⃣ Application Software: programs for users. Example: MS Word, Excel, Photoshop.
  • 3️⃣ Utility Software: maintenance. Example: Antivirus, Disk cleanup.

Language Translators

TranslatorFunction
AssemblerConverts assembly language to machine language.
CompilerConverts whole program at once.
InterpreterConverts line by line.

🌟 Chapter 3: Operating System

Operating System (OS) is the most important software. It is a bridge between: User ↔ Hardware.

Example: When you click mouse, OS tells hardware what to do.

Functions of OS:

  1. Memory Management
  2. File Management
  3. Process Management
  4. Device Management

Examples: Windows, Linux, macOS.

🌟 Chapter 4: Number System

Computers understand only 0 and 1 → Binary (Base 2).

4 number systems:

NameBaseDigits
Decimal100–9
Binary20,1
Octal80–7
Hexadecimal160–9, A–F

Important Terms

  • Bit – smallest unit (0 or 1).
  • Nibble – group of 4 bits. Example: 1010.
  • Byte – 8 bits = 1 byte.

🌟 Chapter 5: Microprocessor

Microprocessor is a small chip – the actual brain chip of computer. It performs calculations & logical operations.

🌟 Chapter 6: Memory and Input Devices

Two main memory types:

  • 1️⃣ RAM (Random Access Memory): temporary, data lost when power off, very fast. Example: Chrome loads in RAM.
  • 2️⃣ ROM (Read Only Memory): permanent, stores startup instructions.

Storage Devices:

Hard Disk, SSD, Pen Drive, CD/DVD.
