📘 Chapter 12: Control Statement in C++

By default program runs sequentially: Line1 → Line2 … But real programs need decisions & repetition.

Control statements “control” the flow of program.

🔹 PART 1: Decision Making (Selection Statements)

🧒 Real‑life example: If it is raining → take umbrella, else don’t. In programming, we use if.

🔸 What is a Condition?

A condition is a question (e.g., marks >= 40). Answer can be true (1) or false (0).

🔸 if Statement

if(condition) { statements; }

If condition true → runs block; false → skips.

Example:
if (marks >= 40) { cout << "Pass"; }
marks = 50 → prints Pass; marks = 20 → prints nothing.

🔸 if-else Statement

if (marks >= 40) { cout << "Pass"; } else { cout << "Fail"; }

One block always runs.

🔸 Nested if

One if inside another – decisions depend on other decisions.

🔸 switch Statement

Compare one variable with many fixed values.

switch(day) { case 1: cout<<"Monday"; break; case 2: cout<<"Tuesday"; break; default: cout<<"Invalid"; }

break stops switch; without it → “fall through”.

🔹 PART 2: Loops (Repetition)

Instead of writing 100 cout lines, use loop to repeat until condition false.

🔸 while Loop

int i = 1; while(i <= 5) { cout << i; i++; }

1. Check condition. 2. If true → run block, go back. 3. If false → exit.

🔸 do-while Loop

do { statements; } while(condition);

Runs at least once (block runs first, then checks).

🔸 for Loop

for(initialization; condition; update) { statements; }

Example: for(int i=1; i<=5; i++) { cout<<i; }

PartMeaning
initializationi=1 (starting point)
conditioni<=5 (loop until false)
updatei++ (change each round)

🔸 break and continue

  • break → stops loop immediately.
  • continue → skips current round, goes to next iteration.

📘 Chapter 14: Library Function and Header Files

Library function = ready-made function written by C++ creators (e.g., sqrt(25)).

  • Saves time
  • Reduces mistakes
  • Makes program shorter

Common Header Files

Header fileContains
<iostream>input/output (cin, cout)
<math.h> or <cmath>math functions (sqrt, pow)
<string.h> or <cstring>string functions (strlen, strcpy)
<ctype.h>character checking (isalpha, isdigit)

📘 Chapter 15: Function in C++

Function = block of code that performs a specific task. (Like calculator buttons.)

Why Functions?

  • Avoid repeating code
  • Organized program
  • Easy to test

Parts of a Function

  1. Declaration (prototype) – tells compiler function exists.
  2. Definition – actual code of function.
  3. Call – using the function (control goes there and returns).

Call by Value

Function receives a copy – original variable safe.

Call by Reference

Function receives original – changes affect original.

// Call by value example void increment(int x) { x++; } // copy, original unchanged // Call by reference void increment(int &x) { x++; } // original changes

📘 Chapter 16: Arrays in C++

To store 100 marks, instead of 100 variables → use array.

Array = collection of same type variables stored together.

int marks[5]; → creates 5 integer spaces. Index starts from 0.

Elementmarks[0]marks[1]marks[2]marks[3]marks[4]
Index01234

Why index 0? Because memory counting starts from base address – first element offset is 0.

2D Array (like table)

int matrix[2][3]; → 2 rows, 3 columns → total 6 elements.

📘 Chapter 17: String Handling in C++

String = group of characters, e.g., "Hello". In C++, string is character array ending with '\0' (null character).

String Functions (from <cstring>)

FunctionAction
strlen(s)returns length of string s
strcpy(dest, src)copies src into dest
strcat(s1, s2)joins s2 at end of s1
strcmp(s1, s2)compares; 0 if equal

📘 Chapter 18: Data Structure in C++ (struct)

Structure allows combining different data types.

struct Student { int roll; char name[30]; float marks; }; Student s1; // create variable s1.roll = 101; // access using dot (.)

Dot operator . connects variable and member.
